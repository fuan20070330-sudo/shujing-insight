# 演示数据说明

## 文件

- `smart-community-demo.csv`：UTF-8 CSV，720 条记录、10 个字段。
- `smart-community-demo.xlsx`：与 CSV 内容一致，用于验证 Excel 导入路径。

## 场景

合成数据模拟 2023-01 至 2024-12 期间，某城市 6 个区、30 个街道的社区商业活力与公共服务指标。字段包括月均收入、到站步行距离、月度客流、公共空间满意度、投诉数、商业活力指数等。

数据中包含程序注入的：

- 少量空值，用于验证缺失审计；
- 极端值，用于验证 IQR 异常检测；
- 2024-06 之后的商业活力结构变化，用于验证变点检测；
- 区域间收入、服务与活力差异，用于验证分组检验；
- 指标间相关关系，用于验证相关性、分组差异和图表推荐。

## 授权与隐私

全部记录由脚本确定性生成，不包含任何真实个人、机构或业务数据。可自由用于本作品演示、测试与评审。重新生成脚本位于工作区 `work/generate-demo.mjs`，随机种子固定为 `20261021`。
